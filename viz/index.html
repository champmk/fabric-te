Example A

Closed-form Clos for 32 nodes × 8 GPUs = 256 GPUs. This is the map. No jobs.

node
One server. Eight GPUs, eight NICs, eight cables — one cable per rail.
rail
Plane r. Every node’s GPU r plugs into the leaf for rail r. Same-rail traffic can stay on one leaf.
leaf
Top-of-rack switch. Here N = D = 32, so there is one leaf per rail: L = 8.
spine
Next switch layer. S = 4. Needed only when a hop changes leaf (usually a different rail).
host cable
GPU NIC → its leaf. E_host = 256 directed links (32 × 8).

L = 8, S = 4, E_host = 256, E_ls = 256, B_bisect = 51 200 Gbps. Same-rail DP on this size never hits a spine.

prev / next steps leaves → one node → same-rail hop → counts.

Example B

One ring AllReduce stopwatch. p = 8 GPUs, M = 64 MiB, B_eff = 50 GB/s, α = 1 µs. No leftover, no Clos admit.

rank
One GPU in the ring, labeled 0…7. Each already has a copy of the weights.
chunk
M / p of the gradient buffer. The ring sends slices, not the whole 64 MiB at once.
hop
Rank i sends one chunk to i+1. One AllReduce is 2(p−1) = 14 hops of that (reduce-scatter then allgather).
α
Per-hop latency, 1 µs. Fourteen hops → 14 µs.
βM
Time to push bytes at 50 GB/s. β = 20 ps/B. Bandwidth term 1.75 · M / B = 2348.810 µs.

T = 14 µs + 2348.810 µs = 2362.810 µs (golden 2 362 810 240 ps). prev / next: ring → slices → hops → T.

Example C

Two 8-GPU ring jobs. Deadline for one collective is 3000 µs. Every rail-0 leaf–spine cable already has leftover 0.

GPU
One chip (board, memory stacks, edge connector). Filled = job 1. Hatched = job 2. X = joint does not place there.
leaf
Top-of-rack switch. r0 is hot (leftover 0). r1 is cool (47.5 GB/s). Same-leaf hops do not use spines.
spine
Fabric switch. The horizontal line is the leaf–spine bus. Crossing rails must use it.
naive
First free GPUs, hop-count path. Ignores leftover and the deadline. May admit and still miss the SLO.
joint
Ranks leftover-aware paths. If leftover on the path is 0, reject (ZeroLeftover). Does not use scratch.

Naive admits both jobs onto mixed rails; both miss the SLO. Joint admits job 1 on leaf r1 (2486 µs) and rejects job 2.

naive / joint chooses the controller. prev / next (or arrow keys) steps idle → J1 → collective → J2.
